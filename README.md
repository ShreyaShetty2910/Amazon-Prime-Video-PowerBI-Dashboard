# Amazon-Prime-Video-PowerBI-Dashboard
This project presents an interactive Power BI dashboard built using the Amazon Prime Video titles dataset. The dashboard provides insights into 9,654 titles by analyzing content across genres, ratings, release years, countries, directors, and content types. It includes KPI cards, interactive charts, and geographic visualizations to help users explore trends and understand the composition of Amazon Prime Video's content library.


# Features
📊 Interactive Power BI Dashboard

📈 KPI Cards (Titles, Ratings, Genres, Directors, Timeline)

🎬 Movies vs TV Shows Analysis

🌍 Country-wise Content Distribution

🎭 Genre Distribution Analysis

⭐ Rating-wise Content Breakdown

📅 Release Year Trends

⚡ Data Cleaning & Transformation using Power Query

📐 DAX Measures for KPIs and Calculations


# Tools Used
Power BI Desktop
Power Query
DAX
CSV Dataset


# Dataset
The dataset contains 9,654 Amazon Prime Video titles released between 1920 and 2021, including details such as title, genre, rating, director, country, release year, and content type.
